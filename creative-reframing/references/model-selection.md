# Model Selection

先识别问题中的主导结构，再选择模型。不要按个人偏好固定使用同一组三个模型。

| 问题信号 | 优先模型 |
| --- | --- |
| “只能二选一”、两个目标互相妨碍 | TRIZ、约束驱动设计 |
| 团队只在已有方案上微调 | SCAMPER、类比迁移、逆向思考 |
| 目标或常识可能未经验证 | 第一性原理、逆向思考 |
| 改一处可能引起连锁反应 | 系统动力学、二阶效应 |
| 不知道先改哪里 | 瓶颈理论、杠杆点 |
| 决策信息不足、代价不对称 | 真实选项、Pre-mortem |
| 多方目标冲突 | 激励分析、博弈论 |

## 正交检查

选择后逐对比较三个模型。如果两个模型会提出基本相同的问题，替换其中一个。常见重复包括：

- 第一性原理与逆向思考都只被用来质疑假设；
- 系统动力学与二阶效应都只被用来列长期影响；
- SCAMPER 与类比迁移都只产出表面功能点子。

模型名称的多样不等于视角正交；以它们在本次问题中承担的功能为准。
