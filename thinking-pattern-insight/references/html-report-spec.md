# HTML Report Spec

## 交付形式

生成一个可以直接用浏览器打开的单文件 HTML：

- CSS 内联；
- SVG 图表内联；
- 不依赖 CDN、外部字体或网络接口；
- 用户回答全部经过 HTML 转义；
- 支持桌面、移动端和打印；
- 图表提供文本替代；
- 支持 `prefers-color-scheme` 和 `prefers-reduced-motion`。

## 内容顺序

1. 一句话画像；
2. 自然语言摘要；
3. 八维雷达图；
4. 八维明细；
5. MBTI 四维中心偏好图；
6. 类型候选；
7. 证据、反证和不确定性；
8. 优势、盲点和场景差异；
9. 自我验证实验；
10. 可展开术语学习区。

## 视觉规则

- 主体内容优先于图表；
- 图表使用稳定尺寸，不因标签变化导致布局跳动；
- 颜色不是唯一信息来源；
- 使用自然语言标签和原始代码双重标注；
- 不用过度装饰、营销式 hero 或大面积渐变；
- 适合阅读和打印，而不是只适合截图。

## 图表

八维雷达图：雷达轴保持固定顺序，便于不同报告横向比较；每个节点展示代码和原始分布，承载中文名称、支持度、等级和自然语言解释。图表下方的明细必须按当前支持度从高到低排序。默认不再显示右侧重复说明；鼠标悬停或键盘聚焦节点时显示详情浮层。移动端和触摸环境通过聚焦状态查看详情，打印版保留完整文字明细。

MBTI 四维图：使用以中线为基准的双向水平条，表达两侧偏好和偏好强度。接近中间时显示“情境依赖”。

## 可访问性

- SVG 使用 `role="img"` 和可读标题；
- 图表后提供等价表格或列表；
- 颜色对比符合可读性要求；
- 支持键盘展开术语区；
- 打印时隐藏交互提示但保留全部内容。
