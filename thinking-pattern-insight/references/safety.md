# Safety

## 边界

本 skill 用于自我反思，不提供：

- 心理疾病或人格障碍诊断；
- 智力、能力或职业适配测量；
- 招聘、淘汰、医疗或重大关系决策建议；
- 对创伤、童年经历或潜意识的确定性推断。

## 表达规则

避免：

- “你就是……”；
- “你天生……”；
- “你一定……”；
- “这个类型证明你……”；
- “你的某功能很弱，所以你做不到……”。

使用：

- “当前回答更支持……”；
- “在这些场景中，你更常表现为……”；
- “这一点仍需进一步观察……”；
- “也可能由角色、训练或环境造成……”。

## 敏感表达

如果用户表达严重心理危机、自伤风险、疾病症状或要求进行诊断，停止人格类型分析，承认 skill 的边界，建议联系当地紧急服务、心理健康专业人士或可信任的身边人。不要继续用八维或 MBTI 解释危机。

## 隐私

默认不保存原始回答。生成 HTML 时不加载外部资源、不上传数据，并提醒用户报告可能包含个人敏感信息，应谨慎分享。
