# Cognitive Functions

这些定义只用于帮助用户理解观察结果，不代表临床或标准化心理测量。

| 代码 | 用户可读名称 | 简明解释 |
|---|---|---|
| Ni | 寻找长期主线 | 从多个线索中寻找整体方向、趋势和潜在含义 |
| Ne | 探索多种可能 | 从一个信息点扩展出多个方向、解释和替代方案 |
| Si | 依靠经验与细节 | 重视已有经验、具体细节、稳定流程和可复用方法 |
| Se | 关注现场与当下 | 关注眼前正在发生的事实，并根据现场变化行动 |
| Ti | 检查逻辑自洽 | 关注概念是否严密、推理是否一致、定义是否清楚 |
| Te | 组织目标与效率 | 关注目标、资源、流程、效率和可衡量结果 |
| Fi | 坚持内在价值 | 关注个人价值、真实感、边界和内在一致性 |
| Fe | 关注关系与氛围 | 关注他人感受、群体氛围、合作关系和共同接受度 |

## 解释规则

- 不把“较明显”解释为“能力强”；
- 不把“较少出现”解释为“能力弱”；
- 不把功能代码单独作为报告标题；
- 每次展示代码时同时展示中文名称和具体行为解释；
- 说明相近功能之间的区别；
- 明确结果会受到场景、训练、压力和角色影响。

## 学习区模板

```text
Ni · 寻找长期主线

它描述的是一种倾向：面对复杂信息时，尝试理解整体方向、长期影响和隐藏联系。

它不等于：准确预测未来、忽略事实细节或一定属于某个 MBTI 类型。

与 Ne 的区别：Ni 更容易把线索收敛成一条主线；Ne 更容易从一个线索扩展出多个可能。
```
