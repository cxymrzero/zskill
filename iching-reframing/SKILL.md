# I Ching Reframing

六十四卦是六十四种情境压缩，用来制造一个不由用户当前叙事直接推导出的观察角度。卦象是隐喻，不是事实来源、诊断工具或未来预测。

## 1. Frame

把输入压缩成：

- 用户正在经历的变化；
- 变化中的核心张力；
- 用户可以影响的行动。

当三项都有明确表述，或缺失项已标为未知时，本步完成。

## 2. Choose

用户指定模式时服从指定；否则询问一次：

> 你想随机取一卦获得意外视角，还是按当前情境匹配一卦？

然后阅读 [`references/hexagrams.md`](references/hexagrams.md)：

- **随机模式**：从 1–64 等概率取一个整数，并公开卦序。若环境不能可靠地产生随机数，让用户给出任意整数，再按 `((n - 1) mod 64) + 1` 映射。不要假装随机。
- **映射模式**：根据核心张力匹配最贴切的“情境压缩”，同时指出一个可能匹配但被排除的卦及排除理由。这样选择是可审视的，不是假装天意。

当模式、卦序和选择依据都明确时，本步完成。

## 3. Interpret

按四层输出，禁止跳层：

1. **卦象原型**：只解释表中主题与张力，不虚构卦辞、爻辞或历史出处。
2. **情境类比**：说明该原型如何映照用户问题。
3. **类比边界**：指出至少一处不适用或可能误导之处。
4. **启发问题**：提出两个能改变用户观察角度的问题。

原型、类比和事实判断被清楚区分后，本步完成。

## 4. Ground

把启发转化为一个现实行动实验，包含动作、时间盒、要观察的信号和停止条件。行动必须基于用户可控范围，不能以卦象作为采取高风险行动的唯一依据。

最终输出必须包含卦名与卦序、选择方式、原型解释、情境类比、类比边界、两个启发问题和一个行动实验；七项齐全才算完成。

## 安全边界

- 不预测健康、死亡、怀孕、诉讼、投资收益或他人的秘密意图。
- 涉及医疗、法律、财务或人身安全时，把卦象限制为反思提示，并明确建议依据事实和合格专业意见决策。
- 不把随机结果描述为命运、征兆、宇宙意志或必然结局。
- 用户反复起卦以逃避决定时，停止继续取卦，转而总结其已知事实、价值与可控行动。
